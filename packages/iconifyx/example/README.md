# iconifyx example

Browse every icon set bundled in iconifyx. Pick a set from the drawer, filter by name, tap an icon to see its codepoint.

## Run

```bash
fvm flutter pub get
fvm flutter run -d macos        # or ios, android, web, linux, windows
```

## Tree-shake / bundle-size verification

The example app depends on every set package and references every icon, so it can't demonstrate bundle scaling. For that, use the standalone harness at `test_apps/two_icon_test/`:

```bash
cd ../../../test_apps/two_icon_test
fvm flutter pub get
fvm flutter build macos --release --tree-shake-icons
find build/macos -name "*.ttf" -path "*flutter_assets*" | xargs ls -la
```

Expected: only `iconifyx_mdi/` and `iconifyx_lucide/` font files in the bundle (no other set's fonts); the two fonts containing the referenced icons shrink to ~700 bytes each.

A single-icon entry point at `lib/main_minimal.dart` is also available for the same verification, but the standalone test app gives cleaner output.

## Regenerating

This example's `lib/generated_index.dart` is regenerated by the upstream tool:

```bash
cd ../../../tools/generator
bun run src/index.ts
```
